## Architecture & Engineering
*(Camera crew leaves. Engineering remains.)*

When I am not handling day-to-day operational issues, I design reliable, secure and maintainable internal systems and automations. 

### Backend & Architecture
I design systems using feature-based architecture with clear separation of concerns. My backend services are built primarily on **Node.js/Express** and **Next.js API Routes**, implementing strict state-machine workflows to prevent invalid data states. I leverage **PostgreSQL** and **Supabase** with versioned database migrations and Row Level Security (RLS) to enforce tenant-aware data access.

### Security & Integrations
Security is integrated at the code level, including **JWT**, expiring magic links, and HttpOnly cookies. I use **AES-256-GCM encryption** for sensitive records where applicable, bcrypt hashing, and **Zod schema validation**. I build event-driven webhook architectures and integrate with REST APIs, enterprise ITSM/ERP systems, and third-party tools like ZapSign and DocuSeal.

### AI & Automation
I use AI as a constrained decision-support layer rather than a novelty feature, surrounding model outputs with structured validation, deterministic rules and fallback behavior. The intended architectural concept is:

Probabilistic model &rarr; structured output &rarr; deterministic validation &rarr; fallback rules &rarr; application action

I integrate models like **Google Gemini** for intent recognition and semantic search (via vector databases), focusing on practical applications such as ticket deflection, intelligent routing, and workflow automation.
